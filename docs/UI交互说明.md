# UI 交互说明

## 1. 项目界面风格

邮差鸟 APP 采用温暖、轻量、卡通化的界面风格。

整体视觉关键词：

- 邮差鸟
- 信封
- 草地
- 云朵
- 柔和天空
- 圆角卡片
- 轻量动效
- 电子相册

手机端偏向“选择、确认、发送”的操作流程。

MatePad 端偏向“横屏播放、自动接收、长期展示”的相框流程。

---

## 2. 手机端主流程

手机端主要用于选择照片或视频，并通过绑定 QQ 邮箱发送给 MatePad 端。

### 2.1 首页

首页显示三个主要入口：

1. 照片
2. 视频
3. 设置

三个入口采用厚纸板卡片风格，卡片上使用扁平图标，不做塑料质感。

### 2.2 点击照片或视频

点击“照片”或“视频”后，界面从信封元素扩展为文件选择窗口。

动效要求：

- 信封从小卡片扩大为大窗口；
- 大窗口保留信封样式；
- 邮差鸟可以趴在信封上方；
- 邮差鸟眼睛朝向下方，看向用户选择的文件；
- 文件以缩略图形式展示；
- 支持多选。

### 2.3 文件确认页

选择文件后进入确认页。

确认页需要显示：

- 已选择文件缩略图；
- 文件数量；
- 文件类型；
- 确认发送按钮；
- 返回重新选择按钮。

确认后才进入发送中状态。

### 2.4 发送中

发送中界面表现邮件正在投递。

动效要求：

- 邮差鸟或信封出现轻微移动；
- 显示发送进度或发送中提示；
- 不要让用户误以为 APP 卡死。

### 2.5 发送成功

发送成功界面显示轻量成功反馈。

动效要求：

- 信封送达；
- 邮差鸟表情变为开心状态；
- 出现成功提示；
- 可以返回首页。

---

## 3. MatePad 端主流程

MatePad 端是电子相册播放端，以横屏展示为主。

### 3.1 主界面

主界面用于播放本地相册资源库中的照片和视频。

要求：

- 默认横屏；
- 图片保持原文件长宽比；
- 不得横向压缩；
- 不得纵向拉伸；
- 不得因为设置面板出现而改变当前照片比例；
- 视频按原比例播放；
- 背景可以使用柔和模糊或留白方式适配不同画幅。

### 3.2 设置入口

左下角设置圆形控件用于打开设置面板。

交互规则：

- 第一次点击：打开设置面板；
- 再次点击：关闭设置面板；
- 设置面板打开时，主界面照片仍保持原始长宽比；
- 设置面板不得挤压、拉伸或改变主图显示比例。

### 3.3 设置面板

设置面板采用卡片形式出现。

设置面板建议包含：

1. 绑定 QQ 邮箱；
2. QQ 邮箱授权码；
3. 自动检查开关；
4. 上次检查时间；
5. 当前邮箱状态；
6. 已接收文件数量；
7. 立即检查一次；
8. 检查更新；
9. 当前版本号。

敏感信息输入框应支持隐藏显示。

### 3.4 年份选择动效

当用户选择播放年份时，界面进入年份选择状态。

动效要求：

- 当前年份显示在中间；
- 相邻的前一年和后一年分别出现在上下位置；
- 用户可以通过上下滑动切换年份；
- 切换时年份上下滚动；
- 选中年份时，整个画面叠加一层淡淡的毛玻璃效果；
- 毛玻璃效果不能遮挡年份文字识别；
- 退出年份选择后，恢复正常播放画面。

### 3.5 自动接收提示

MatePad 端每 15 分钟自动检查邮箱。

自动检查时不打断主界面播放。

可以在角落显示轻提示，例如：

- 正在检查新照片
- 已收到 3 个新文件
- 当前网络异常
- 邮箱登录失败，请检查设置

提示应短暂停留后自动消失。

---

## 4. 空状态界面

当 MatePad 端还没有收到任何照片或视频时，显示空状态界面。

空状态界面建议包含：

- 邮差鸟形象；
- 信封或邮筒元素；
- 提示文案：等待手机端发送照片或视频；
- 设置入口；
- 立即检查一次按钮。

---

## 5. 图片显示规则

MatePad 端图片显示必须遵守：

1. 保持原图比例；
2. 不拉伸；
3. 不横向压缩；
4. 不强制铺满屏幕；
5. 横图优先适配屏幕宽度；
6. 竖图优先适配屏幕高度；
7. 剩余区域可使用模糊背景或留白填充。

---

## 6. 动效原则

所有动效应遵守以下原则：

1. 动效轻量，不影响性能；
2. 不打断主流程；
3. 不影响 MatePad 长时间播放稳定性；
4. 设置、年份选择、接收提示都应是覆盖层逻辑，而不是挤压主画面；
5. 邮差鸟表情和眼睛可以做轻微变化，但不能改变角色基本造型。

---

## 7. 当前优先级

优先实现 MatePad 端：

1. 横屏相册播放；
2. 图片保持原比例；
3. 设置按钮打开和关闭；
4. 设置面板不改变主图比例；
5. 年份选择毛玻璃动效；
6. 邮箱自动检查状态提示。

手机端后续再完善选择、确认、发送、成功流程。
