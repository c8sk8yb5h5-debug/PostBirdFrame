# MatePad 端界面与交互规则

本文件为 MatePad 端 App 的界面和交互基准。后续 APK 开发必须以项目内“MatePad界面优化与预览”的操作界面为准，不得再临时改成普通设置页或工程测试页样式。

## 1. 主界面结构

MatePad 端为横屏电子相框界面。

主画面以照片 / 视频播放区为中心，播放内容保持原文件长宽比，不允许因为设置面板、按钮或其他浮层出现而被横向压缩、纵向拉伸或裁切变形。

主界面不应长期显示工程提示文案，例如：

```text
左右滑动切换
设置页接收后，返回主界面查看最新照片
等待手机端发送照片或视频
```

必要提示只能作为轻量状态浮层出现，不能破坏相框视觉。

## 2. 时间与设置控件

底部角落使用圆形控件组，样式以“MatePad界面优化与预览”为准。

控件组合为三个圆：

```text
1. 年份圆
2. 月/日圆：同一个圆内用斜排或上下排显示月、日，并以 / 分隔
3. 设置圆
```

三个圆形控件尺寸应一致，视觉风格一致。

设置圆再次点击时必须关闭设置面板。

## 3. 设置面板

点击设置圆后，右侧出现设置卡片 / 管理面板。

设置面板出现时：

```text
1. 主界面照片保持原比例
2. 不压缩照片宽度
3. 不改变照片长宽比
4. 只允许主画面整体轻微弱化或蒙层处理
```

设置面板内保留：

```text
QQ 邮箱
QQ 邮箱授权码
保存设置
清除配置
测试邮箱连接
立即检查
检查更新
15 分钟自动检查开关
当前版本
```

## 4. 播放交互

照片 / 视频播放区支持自动播放和手动控制。

手动控制规则：

```text
左滑：下一张
右滑：上一张
手动滑动后，自动播放暂停约 12 秒，再继续轮播
```

播放区不需要长期显示“左右滑动切换”文字。

## 5. 年月日选择交互

点击年份圆时，画面应覆盖淡淡毛玻璃效果。

选择器中当前年份位于中间，相邻两个年份在上下出现，可通过上下滑动切换。

月份、日期后续按同一交互风格扩展。

## 6. 素材缩略图

缩略图切换大图属于“MatePad界面优化与预览”既有交互方向，可以后续接入，但不应先用普通列表或工程面板破坏主界面。

## 7. 开发约束

后续所有 MatePad 端界面修改必须先对照本文件，不允许只按临时测试逻辑修改 UI。

功能测试入口可以存在，但必须收纳在设置面板或轻量弹窗中，不能成为主界面主要视觉。
