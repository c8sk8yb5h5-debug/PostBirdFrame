# MatePad 端第一轮开发指令

## 1. 执行目标

请在 `matepad-app/` 目录下创建 MatePad 端 Android 原生项目骨架。

当前只做第一轮 MVP 骨架，不要开发手机端。

目标是先完成一个可以运行和预览的 MatePad 横屏电子相框界面。

## 3. 技术要求

MatePad 端使用：

- Kotlin
- Android 原生 APP
- Jetpack Compose
- Gradle
- 包名：`com.postbird.frame.matepad`
- APP 显示名称：`邮差鸟相框`
- 初始版本：`1.0.0`

---

## 4. 第一轮只实现这些内容

### 4.1 横屏主界面

实现 MatePad 横屏电子相册主界面。

要求：

1. APP 默认横屏；
2. 主区域用于显示照片或空状态；
3. 没有照片时显示空状态界面；
4. 空状态界面显示“等待手机端发送照片或视频”；
5. 左下角固定显示设置圆形按钮。

### 4.2 图片显示规则

先内置 1 张占位图片或占位卡片用于测试显示。

要求：

1. 图片保持原始比例；
2. 不横向压缩；
3. 不纵向拉伸；
4. 不强制铺满全屏；
5. 设置面板打开时，图片比例不变。

### 4.3 设置按钮

左下角设置按钮交互：

1. 第一次点击：打开设置面板；
2. 再次点击：关闭设置面板；
3. 设置按钮始终固定在左下角；
4. 设置面板不得挤压主画面。

### 4.4 设置面板

设置面板以覆盖层形式出现。

第一轮设置面板先包含以下字段：

1. QQ 邮箱输入框；
2. QQ 邮箱授权码输入框；
3. 自动检查开关；
4. 立即检查一次按钮；
5. 检查更新按钮；
6. 当前版本号；
7. 上次检查时间占位文本；
8. 邮箱状态占位文本。

本轮只做 UI，不需要真实连接邮箱。

### 4.5 毛玻璃覆盖逻辑

设置面板打开时，可以给主界面叠加轻微毛玻璃或半透明遮罩。

要求：

1. 不改变主图比例；
2. 不挤压主图；
3. 不影响关闭设置面板；
4. 动效轻量。

---

## 5. 本轮不要实现的内容

第一轮不要实现：

1. QQ 邮箱真实登录；
2. IMAP/SMTP 收发；
3. 15 分钟后台检查；
4. 附件下载；
5. Room 数据库；
6. GitHub Release 真实更新；
7. 手机端代码；
8. 复杂年份选择动效。

这些放到后续阶段。
