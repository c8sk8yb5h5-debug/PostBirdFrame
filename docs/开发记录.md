8. GitHub Actions 构建成功；
9. 已下载 debug APK；
10. 已在 MatePad 上安装成功；
11. 打开后界面正常。

### 当前验证结果

MatePad 端第一轮 APK 已通过以下基础测试：

1. 可以安装；
2. 可以打开；
3. 默认横屏显示；
4. 显示“等待手机端发送照片或视频”；
5. 左下角设置按钮可见；
6. 点击设置按钮可以打开设置面板；
7. 再次点击设置按钮可以关闭设置面板。

### 当前版本状态

当前版本仍为第一轮 MVP 骨架版本。

已完成的是界面骨架和云端构建流程，暂未接入真实邮箱、附件下载、本地资源库和 GitHub Release 更新功能。

### 下一阶段建议

第二轮优先处理：

1. 设置页输入内容本地保存；
2. QQ 邮箱和授权码使用本机加密存储；
3. 设置页显示保存成功状态；
4. 重启 APP 后可以读取已保存配置；
5. 仍然不得在代码或 GitHub 仓库中写入真实邮箱授权码。

## 2026-05-22 MatePad 第二轮 APK 测试

### 已完成

1. 已建立 `docs/MatePad端第二轮开发指令.md`；
2. 已新增 `MailSettings` 设置数据模型；
3. 已新增 `MailSettingsStore` 本地设置存储类；
4. 当前版本使用 Android 系统自带 `SharedPreferences` 保存设置；
5. 设置页已新增“保存设置”按钮；
6. 设置页已新增“清除配置”按钮；
7. QQ 邮箱输入内容可以保存；
8. QQ 邮箱授权码输入内容可以保存；
9. 自动检查开关状态可以保存；
10. 重启 APP 后可以读取已保存配置；
11. GitHub Actions 第二轮构建成功；
12. 第二轮 APK 已在 MatePad 上覆盖安装成功；
13. 第二轮安装测试通过。

### 当前验证结果

MatePad 端第二轮 APK 已通过以下测试：

1. APP 可以正常打开；
2. 设置按钮可以打开设置面板；
3. 再次点击设置按钮可以关闭设置面板；
4. 输入测试邮箱后可以保存；
5. 输入测试授权码后可以保存；
6. 自动检查开关状态可以保存；
7. 关闭 APP 后重新打开，设置内容仍然存在；
8. 点击“清除配置”后，邮箱、授权码和开关状态可以恢复默认。

### 当前版本状态

当前版本仍未接入真实 QQ 邮箱登录、IMAP 收件、附件下载、本地播放资源库和 GitHub Release 更新。

第二轮只完成设置页本地保存能力。

### 下一阶段建议

第三轮优先处理：

1. 将 `MailSettingsStore` 从普通 `SharedPreferences` 升级为加密保存；
2. 使用 Android KeyStore 或 EncryptedSharedPreferences；
3. 避免 QQ 邮箱授权码以普通明文形式保存在本机；
4. 保持设置页现有交互不变；
5. 构建新 APK 后继续在 MatePad 上覆盖安装测试。
