# 技术选型与包名规则

## 1. 当前开发目标

当前阶段优先开发 MatePad 端“邮差鸟相框”。

手机端暂不优先完整开发，先保留目录和规则。

MatePad 端 MVP 目标是：

1. 横屏电子相册播放；
2. 图片和视频保持原始比例；
3. 设置面板打开和关闭；
4. 本机保存 QQ 邮箱和授权码；
5. 每 15 分钟自动检查邮箱；
6. 自动下载来自绑定邮箱的图片和视频附件；
7. 保存到本地资源库；
8. 支持 GitHub Public Release 检查更新。
