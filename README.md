# PostBirdFrame

邮差鸟相框项目。

本项目用于开发一套手机端与 MatePad 端配合使用的电子相册 APP。

手机端负责选择照片或视频，并通过绑定 QQ 邮箱发送邮件。

MatePad 端负责定时检查邮箱，接收图片和视频附件，保存到本地资源库，并以电子相册形式播放。
