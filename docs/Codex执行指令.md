# Codex 执行指令

## 1. 项目身份

本项目名称为 PostBirdFrame。

项目包含两个端：

- mobile-app：邮差鸟手机端；
- matepad-app：邮差鸟相框 MatePad 端。

当前阶段优先开发 MatePad 端，不要优先开发手机端完整流程。

---

## 2. Codex 开始工作前必须先阅读的文档

开始任何代码修改前，必须先阅读以下文档：

1. `README.md`
2. `docs/发送与更新规则.md`
3. `docs/UI交互说明.md`
4. `docs/MatePad端MVP任务清单.md`
5. `docs/版本发布规则.md`
6. `shared/素材命名规则.md`
7. `docs/开发记录.md`

不要跳过文档直接写代码。

---

## 3. 当前最高优先级

当前只优先完成 MatePad 端 MVP。

开发顺序如下：

1. 横屏电子相册播放界面；
2. 图片和视频保持原始比例；
3. 左下角设置按钮；
4. 设置面板打开和关闭；
5. 设置面板不改变主图比例；
6. 设置页邮箱配置；
7. 本机加密保存邮箱配置；
8. 每 15 分钟自动检查 QQ 邮箱；
9. 下载来自绑定邮箱的图片和视频附件；
10. 本地播放资源库；
11. GitHub Public Release 检查更新。

---

## 4. MatePad 端界面要求

MatePad 端是横屏电子相册，不是普通手机 APP。

主界面要求：

1. 默认横屏显示；
2. 图片保持原始比例；
3. 视频保持原始比例；
4. 不得拉伸图片；
5. 不得横向压缩图片；
6. 设置面板出现时，不得改变当前照片或视频比例；
7. 设置面板应作为覆盖层出现；
8. 设置按钮固定在左下角；
9. 再次点击设置按钮可以关闭设置面板。

---

## 5. 邮箱接收规则

MatePad 端每 15 分钟自动检查一次绑定 QQ 邮箱。

只处理来自绑定 QQ 邮箱本身的邮件附件。

允许下载的附件类型：

图片：

- jpg
- jpeg
- png
- webp

视频：

- mp4
- mov
- m4v

其他附件类型全部忽略。

同一附件不得重复下载。

---

## 6. 本地安全规则

不得在代码中写死以下内容：

1. QQ 邮箱授权码；
2. QQ 邮箱密码；
3. GitHub token；
4. 私有 API token；
5. 用户个人配置。

邮箱地址和授权码只能由用户在 APP 设置页输入，并保存在本机加密存储中。

建议使用 Android KeyStore 或等效机制。

---

## 7. GitHub 更新规则

当前仓库为公开仓库 Public。

APP 检查 GitHub Release 更新时，不需要 GitHub token。

MatePad 端只识别文件名中包含 `MatePad` 的 APK。

手机端只识别文件名中包含 `Mobile` 的 APK。

推荐命名：

```text
PostBird-MatePad-v1.0.0.apk
PostBird-Mobile-v1.0.0.apk
```

---

## 8. 不允许优先做的内容

当前阶段不要优先做以下内容：

1. 手机端完整发送流程；
2. 多用户家庭账号体系；
3. 云端同步；
4. 复杂主题皮肤；
5. 高级动画系统；
6. 与 MVP 无关的大规模重构。

---

## 9. 每次修改后的要求

每次完成代码修改后，需要同步更新：

1. `docs/开发记录.md`
2. 相关 README 文档
3. 相关任务清单状态

提交说明需要写清楚本次完成了什么。

---

## 10. 当前一句话目标

先把 MatePad 端做成一个可以长期横屏播放、可以打开设置页、可以保存邮箱配置、可以自动收取图片和视频附件、可以通过 GitHub Release 更新的电子相框 APP。
