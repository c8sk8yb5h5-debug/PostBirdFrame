# 联网更新发布流程

## 目标

建立 MatePad 端 APK 发布流程。后续 APP 内更新功能将从 GitHub Releases 获取最新 APK。

## 工作流文件

```text
.github/workflows/release-matepad.yml
```

## 使用方式

1. 打开 GitHub 仓库；
2. 进入 Actions；
3. 选择 Release MatePad APK；
4. 点击 Run workflow；
5. tag 填写版本号，例如 `matepad-v1.1.0`；
6. 运行成功后，Releases 页面会出现 `PostBird-MatePad-latest.apk`。

## 后续 APP 内更新逻辑

1. APP 请求 GitHub 最新 Release；
2. 找到 APK 下载地址；
3. 下载 APK 到本机；
4. 调用系统安装器；
5. 用户确认安装。
