5. 已新增 `MailConnectionResult` 连接结果模型；
6. 已新增 `QqMailConnectionTester`；
7. 设置页已新增“测试邮箱连接”按钮；
8. QQ 邮箱 IMAP 参数使用 `imap.qq.com:993`；
9. 邮箱连接测试使用后台线程执行；
10. 连接测试只打开 INBOX，且使用 `Folder.READ_ONLY`；
11. 不下载附件；
12. 不读取完整正文；
13. 不删除、移动或标记邮件；
14. 第四轮构建时出现邮件依赖重复资源冲突；
15. 已通过 `packaging.resources.excludes` 修复重复资源冲突；
16. 已修复连接测试提示不明显的问题；
17. 设置面板顶部新增“当前提示”卡片；
18. 关键提示同步通过 Android Toast 弹出；
19. 提示修复版 GitHub Actions 构建成功；
20. 提示修复版 APK 已在 MatePad 上覆盖安装成功；
21. 第四轮提示修复版测试通过。

### 当前验证结果

MatePad 端第四轮 APK 已通过以下测试：

1. APP 可以正常打开；
2. APP 仍然默认横屏；
3. 设置按钮可以打开设置面板；
4. 设置面板可以关闭；
5. 邮箱和授权码仍可加密保存；
6. 空邮箱或空授权码会提示“邮箱或授权码为空”；
7. 非 QQ 邮箱会提示“当前仅支持 QQ 邮箱”；
8. 错误授权码会提示授权码错误、IMAP 未开启、连接失败或类似失败原因；
9. 正确 QQ 邮箱和正确授权码可以连接成功；
10. 连接结果会显示在“当前提示”卡片；
11. 连接结果会通过系统 Toast 弹出；
12. 连接测试不会卡死界面。

### 当前版本状态

当前版本已完成 QQ 邮箱 IMAP 连接测试能力。

当前仍未实现：

1. 每 15 分钟自动检查；
2. 自动读取邮件列表；
3. 附件筛选；
4. 图片和视频附件下载；
5. 本地播放资源库；
6. GitHub Release 更新。

第五轮优先处理：

1. 读取收件箱最近邮件列表；
2. 只筛选来自绑定 QQ 邮箱自己的邮件；
3. 只统计图片和视频附件；
4. 不下载附件；
5. 设置页显示“发现可接收附件数量”；
6. 继续保持只读访问，不修改邮件状态。
