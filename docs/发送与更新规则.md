# 发送与更新规则

## 1. 项目仓库

GitHub 仓库地址：

https://github.com/c8sk8yb5h5-debug/PostBirdFrame.git

当前采用一个仓库管理两个端：

- mobile-app：手机端
- matepad-app：MatePad 相框端
- docs：开发文档
- shared：公共素材与规则

仓库为公开仓库 Public。

公共仓库中不得保存 QQ 邮箱授权码、邮箱密码、GitHub token 或任何个人配置。

## 2. 端口分工

### 2.1 手机端：邮差鸟

手机端负责选择照片或视频，并通过绑定 QQ 邮箱发送邮件。

主要功能包括：

1. 选择照片；
2. 选择视频；
3. 支持多选；
4. 显示所选文件缩略图；
5. 确认后发送邮件；
6. 显示发送中、发送成功、发送失败状态。

### 2.2 MatePad 端：邮差鸟相框

MatePad 端负责接收邮件附件、保存本地资源并进行电子相册播放。

主要功能包括：

1. 横屏电子相册播放；
2. 每 15 分钟自动检查 QQ 邮箱；
3. 只处理来自绑定邮箱的邮件；
4. 只下载图片和视频附件；
5. 保存到本地相册资源库；
6. 自动加入播放列表；
7. 设置页显示邮箱状态、接收状态和版本更新状态；
8. 通过 GitHub Public Release 检查版本更新。

## 3. 邮箱绑定规则

手机端和 MatePad 端绑定同一个 QQ 邮箱。

手机端使用该邮箱发送邮件。

MatePad 端使用该邮箱检查收件箱，并只处理来自该邮箱本身的邮件附件。

判断规则：

- 发件邮箱 = 当前绑定 QQ 邮箱：允许处理；
- 发件邮箱 ≠ 当前绑定 QQ 邮箱：忽略；
- 发件邮箱为空、异常或无法识别：忽略。

## 4. 自动检查规则

MatePad 端每 15 分钟自动检查一次绑定邮箱。

检查过程应在后台执行，不得打断电子相册主界面的照片或视频播放。

设置页需要提供“立即检查一次”按钮。

## 5. 附件类型规则

MatePad 端只处理图片和视频附件。

建议支持的图片格式：

- jpg
- jpeg
- png
- webp

建议支持的视频格式：

- mp4
- mov
- m4v

其他附件类型全部忽略。

## 6. 下载与去重规则

附件下载成功后，APP 自动保存到 MatePad 本地相册资源库。

每个附件需要记录以下信息：

- 邮件 ID
- 附件文件名
- 附件大小
- 附件类型
- 接收时间
- 本地保存路径
- 下载状态

去重判断建议使用：

- 邮件 ID
- 附件文件名
- 附件大小

如果附件已成功下载，后续自动检查时不再重复下载。

## 7. 异常处理规则

如果出现网络异常、邮箱登录失败、附件下载失败或文件保存失败，APP 不得中断主界面播放。

异常信息只在设置页显示。

设置页建议显示：

- 上次检查时间
- 上次检查结果
- 当前邮箱连接状态
- 最近一次失败原因
- 已成功接收文件数量

## 8. GitHub 更新规则

APP 版本更新通过 GitHub Public Release 实现。

公共 Release 可以存放：

- APK 安装包
- 最新版本号
- 更新说明
- 更新发布时间

公共仓库不得存放：

- QQ 邮箱授权码
- QQ 邮箱密码
- GitHub token
- 私有 Release API token
- 用户个人配置

使用公共仓库发布 Release 时，APP 不需要 GitHub token。

## 9. APK 命名规则

建议后续 Release 中使用以下命名：

- PostBird-Mobile-v1.0.0.apk
- PostBird-MatePad-v1.0.0.apk

MatePad 端检查更新时，只识别包含 `MatePad` 的 APK。

手机端检查更新时，只识别包含 `Mobile` 的 APK。

## 10. 安全规则

以下信息不得写死在 APK、GitHub 仓库或公开代码中：

- QQ 邮箱授权码
- QQ 邮箱密码
- GitHub token
- 私有 API token
- 用户个人配置

邮箱地址、授权码、更新 token 等配置只允许保存在用户本机。

MatePad 端和手机端都应使用 Android KeyStore 或等效机制进行本机加密保存。
