# MatePad 端界面与交互规则

本文件为 MatePad 端 App 的界面和交互基准。后续 APK 开发必须以项目内“MatePad界面优化与预览”的操作界面和交互动效为准，不得以当前临时 Compose 测试页为基础继续小修小补。

## 0. 当前纠偏结论

1. `1.4.48` 及此前版本只可视为功能验证版本，用于验证 QQ 邮箱接收、版本更新、图片/视频播放、左右滑动切换等底层能力。
2. `1.4.48` 的操作界面不是最终界面基准。
3. 后续 MatePad 端 UI 必须从“MatePad界面优化与预览”的界面结构重新落地，再把已验证的功能叠加进去。
4. 禁止在 `1.4.48` 当前界面样式上继续局部调整，避免越改越偏。

## 1. 主界面结构

MatePad 端为横屏电子相框界面。

主画面以照片 / 视频播放区为中心，播放内容保持原文件长宽比，不允许因为设置面板、按钮或其他浮层出现而被横向压缩、纵向拉伸或裁切变形。

主界面不应长期显示工程提示文案，例如：

```text
左右滑动切换
设置页接收后，返回主界面查看最新照片
等待手机端发送照片或视频
```

必要提示只能作为轻量状态浮层出现，不能破坏相框视觉。

## 2. 时间与设置控件

底部角落使用圆形控件组，样式以“MatePad界面优化与预览”为准。

控件组合为三个圆：

```text
1. 年份圆
2. 月/日圆：同一个圆内用斜排或上下排显示月、日，并以 / 分隔
3. 设置圆
```

三个圆形控件尺寸应一致，视觉风格一致。

设置圆再次点击时必须关闭设置面板。

## 3. 设置面板

点击设置圆后，右侧出现设置卡片 / 管理面板。

设置面板出现时：

```text
1. 主界面照片保持原比例
2. 不压缩照片宽度
3. 不改变照片长宽比
4. 只允许主画面整体轻微弱化或蒙层处理
```

设置面板内保留：

```text
QQ 邮箱
QQ 邮箱授权码
保存设置
清除配置
测试邮箱连接
立即检查
检查更新
15 分钟自动检查开关
当前版本
```

这些功能必须叠加到预览版设置面板中，不得重新设计成普通工程设置页。

## 4. 播放交互

照片 / 视频播放区支持自动播放和手动控制。

手动控制规则：

```text
左滑：下一张
右滑：上一张
手动滑动后，自动播放暂停约 12 秒，再继续轮播
```

播放区不需要长期显示“左右滑动切换”文字。

## 5. 年月日选择交互

点击年份圆时，画面应覆盖淡淡毛玻璃效果。

选择器中当前年份位于中间，相邻两个年份在上下出现，可通过上下滑动切换。

月份、日期后续按同一交互风格扩展。

## 6. 素材缩略图

缩略图切换大图属于“MatePad界面优化与预览”既有交互方向，可以后续接入，但不应先用普通列表或工程面板破坏主界面。

## 7. 功能叠加方式

已验证功能按以下方式嵌入：

```text
QQ 邮箱接收：放入设置面板的“立即检查”入口
版本更新：放入设置面板的“检查更新”入口
邮箱配置：放入设置面板，不进入主界面
自动播放：放入相框播放区域
左右滑动：放入相框播放区域
视频播放：放入相框播放区域
```

功能代码可以复用，但 UI 容器必须按预览版重建。

## 8. 开发约束

后续所有 MatePad 端界面修改必须先对照本文件。

禁止把 MatePad 端主界面改成纯工程测试页。

禁止继续在当前临时 Compose 页面基础上做视觉微调。

禁止把“邮箱更新”“立即检查”“调试状态”作为主界面视觉中心。

功能测试入口可以存在，但必须收纳在设置面板或轻量弹窗中，不能成为主界面主要视觉。

下一轮开发任务不是继续修 `1.4.48` 界面，而是重建 MatePad 播放主界面，再迁移现有功能。
