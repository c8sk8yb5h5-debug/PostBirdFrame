# MatePad 端 MVP 任务清单

## 1. 当前目标

优先完成 MatePad 端“邮差鸟相框”的最小可用版本。

MVP 版本目标：

1. 可以横屏播放本地图片和视频；
2. 图片和视频保持原始比例；
3. 设置面板可以打开和关闭；
4. 设置面板不改变主界面照片比例；
5. 可以在设置页填写 QQ 邮箱和授权码；
6. MatePad 端每 15 分钟自动检查一次邮箱；
7. 只下载来自绑定 QQ 邮箱的图片和视频附件；
8. 下载后自动加入本地播放资源库；
9. 支持 GitHub Public Release 检查更新。

---

## 2. 第一阶段：界面骨架

### 2.1 横屏主界面

任务：

- 建立 MatePad 横屏主界面；
- 主区域用于播放照片或视频；
- 左下角放置设置圆形按钮；
- 默认显示空状态界面。

验收标准：

- APP 打开后进入横屏相框界面；
- 没有文件时显示空状态；
- 设置按钮位置固定在左下角。

### 2.2 图片显示规则

任务：

- 图片必须保持原始比例；
- 不得横向压缩；
- 不得纵向拉伸；
- 不得强制铺满全屏；
- 剩余区域可使用模糊背景或留白。

验收标准：

- 横图显示正常；
- 竖图显示正常；
- 设置面板打开时，当前图片比例不变。

### 2.3 设置面板

任务：

- 点击左下角设置按钮打开设置面板；
- 再次点击设置按钮关闭设置面板；
- 设置面板以覆盖层形式出现；
- 设置面板不得挤压主画面。

验收标准：

- 设置面板可以打开；
- 设置面板可以关闭；
- 主图比例不发生变化。

---

## 3. 第二阶段：本地配置

### 3.1 邮箱配置

任务：

设置页需要提供：

- QQ 邮箱输入框；
- QQ 邮箱授权码输入框；
- 保存设置按钮；
- 显示/隐藏授权码按钮。

验收标准：

- 用户可以输入邮箱；
- 用户可以输入授权码；
- 授权码默认隐藏；
- 保存后下次打开仍能读取配置。

### 3.2 本机加密保存

任务：

- 邮箱和授权码只允许保存在本机；
- 使用 Android KeyStore 或等效机制加密保存；
- 不得写死在代码中；
- 不得上传到 GitHub。

验收标准：

- GitHub 仓库中没有真实邮箱授权码；
- APK 中没有写死真实授权码；
- 删除本机配置后，APP 不再自动检查邮箱。

---

## 4. 第三阶段：邮箱自动接收

### 4.1 自动检查

任务：

- MatePad 端每 15 分钟自动检查 QQ 邮箱；
- 设置页提供“立即检查一次”按钮；
- 检查过程不得打断主界面播放。

验收标准：

- 可以手动检查邮箱；
- 可以定时自动检查；
- 播放界面不会被中断。

### 4.2 邮件筛选

任务：

- 只处理来自绑定 QQ 邮箱的邮件；
- 其他发件人的邮件全部忽略；
- 无法识别发件人的邮件忽略。

验收标准：

- 本邮箱发送的附件可以被接收；
- 其他邮箱发送的附件不会进入播放资源库。

### 4.3 附件筛选

任务：

支持图片格式：

- jpg
- jpeg
- png
- webp

支持视频格式：

- mp4
- mov
- m4v

其他文件类型忽略。

验收标准：

- 图片附件可以下载；
- 视频附件可以下载；
- 非图片和视频附件不会进入资源库。

### 4.4 去重记录

任务：

下载附件后记录：

- 邮件 ID；
- 附件文件名；
- 附件大小；
- 附件类型；
- 接收时间；
- 本地路径；
- 下载状态。

验收标准：

- 同一附件不会重复下载；
- 已下载文件能被播放列表识别。

---

## 5. 第四阶段：本地播放资源库

任务：

- 建立本地资源库；
- 管理已接收的图片和视频；
- 自动加入播放列表；
- 支持按接收时间排序；
- 支持空状态和有内容状态切换。

验收标准：

- 新收到文件后可以自动播放；
- 重启 APP 后仍能读取本地资源；
- 删除文件后播放列表能更新。

---

## 6. 第五阶段：版本更新

任务：

- 从 GitHub Public Release 获取最新版本；
- 对比当前版本号；
- 识别 MatePad 端 APK；
- 显示更新说明；
- 引导下载安装。

验收标准：

- 设置页可以检查更新；
- 有新版本时显示更新信息；
- 只下载包含 MatePad 的 APK；
- 使用公开仓库时不需要 GitHub token。

---

## 8. MVP 优先级结论

当前阶段只做 MatePad 端。

优先顺序：

1. 横屏播放界面；
2. 设置面板；
3. 本机邮箱配置；
4. 邮箱自动检查；
5. 附件下载；
6. 本地播放资源库；
7. GitHub Release 更新。
